# Agent docs

Before you start a task, read the doc that applies to the task.

- `effect.md`: Read this doc before you write Effect code.
- `domain.md`: This doc gives the layout of the domain docs and tells you how to use them. This repo has one context: one `GLOSSARY.md` and `docs/adr/` at the repo root.
- `testing.md`: Read this doc before you write tests. It gives the test types and the rules for recorded tests and live tests.
